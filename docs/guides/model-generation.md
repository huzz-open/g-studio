# 使用模型生成

返回[文档索引](../README.md)。本页说明网页操作；安装、硬件和打包见[后端部署](../../services/generation-python/README.md)。

## 选择运行方式

| 场景 | 启动方式 | 网页连接 |
| --- | --- | --- |
| 只需轮廓近似 | 在线体验或 `npm run dev:web` | 不需要服务 |
| 本机网页与 AI | `npm run dev` | 直连接口 |
| 已有网页，只启动 AI | `sh start-generation.sh` | 直连接口 |
| 在线网页通过服务器使用本机算力 | 服务器部署中转，本机启动带 `--relay` 的后端 | 连接本地设备 |

首次 AI 启动会下载运行环境和模型；已有完整资源会复用。启动服务不会自动上传图片，也不会把默认轮廓近似切换成 AI。

## 连接本机服务

1. 启动后端，等待日志显示服务已就绪。
2. 在 **设置 → 模型生成 → 连接服务** 选择“直连接口”。
3. 点击“测试连接”，检查计算设备显示为 CPU 或 GPU。本地开发会自动取得连接凭证。
4. 选择可用的生成方式；模型仍在准备或服务报错时，先查看后端日志。

在线网页访问本机服务需要配置允许的网页来源、直连凭证，并可能需要浏览器本地网络权限。具体配置见[公网网页连接](../../services/generation-python/README.md#public-websites)。

## 计算设备与支持范围

| 设备 | 当前行为 | 验证范围 |
| --- | --- | --- |
| Windows x64 CPU | 完整 CPU 推理与离线包 | 已完成真实生成和搬移验证 |
| Windows NVIDIA | 使用 CUDA 12.4 / PyTorch 2.6.0；探测或运算不兼容时回退 CPU | 可在 CPU 电脑组装完整 CUDA 依赖包，实际显卡推理需对应硬件验证 |
| Mac M 系列 ARM64，目标 macOS 14+ | 优先 MPS；探测不可用或遇到已识别的算子兼容、内存错误时回退 CPU | Apple M5（24 GB、macOS 26.5.2）已通过完整离线包启动、API 生成和外形检查；其他 Mac 待验证 |
| Windows Intel / AMD 显卡 | 使用 CPU | 暂不支持 XPU / ROCm 加速，不提供以其 GPU 支持命名的包 |

当前模型不支持 NVIDIA GeForce MX150（2 GB）的 GPU 推理，请使用 `--cpu`。

连接成功后，界面会显示实际使用的 `CPU`、`GPU · NVIDIA CUDA` 或 `GPU · Apple MPS`。普通“有显卡”不等于当前模型能使用该显卡；驱动、PyTorch 构建和具体算子都要匹配。模型权重没有改变，适配的是执行这些权重所需的运算后端。GPU 任务回退时会保留原始上传图片，从头在 CPU 重试一次。

离线包包含对应平台的 Python 和依赖；目标电脑仍需有兼容的系统与显卡驱动。打包和强制设备选择见[后端部署](../../services/generation-python/README.md#portable-packages)。

## 通过公网中转

先按[中转部署说明](../../services/generation-relay/README.md)启动 HTTPS/WSS 服务。在承担计算的电脑上运行：

```sh
sh start-generation.sh --relay wss://your-domain.example/generation/worker --pair
```

在网页“连接本地设备”中填写中转 HTTPS 地址及终端显示的 10 位大写字母数字配对码，点击配对即可连接，无需返回终端确认。有效配对码本身就是使用本机模型服务的授权；只分享给愿意授权的人。配对码 5 分钟内有效、单次使用，连接授权最长有效 30 天。后续启动可省略 `--pair`，保留原有凭证数据目录与中转地址。

中转服务和本机后端需要同时在线。图片与模型会经过中转服务器的短时内存缓冲，用完即释放，不再写入中转磁盘；保存规则、授权和撤销方式见[中转说明](../../services/generation-relay/README.md)。中转服务器只负责传输，计算发生在运行生成后端的机器上。

## 独立生成与查看

1. 进入“模型生成”选择图片，左侧参数直接平铺，调整后点击“生成模型”。
2. 视口左上角的悬浮队列集中展示任务，点击展开或收起，选择任务可查看进度与结果。
3. 完成的模型自动保存在当前浏览器中，无需“应用结果”。即使服务断开，也能进入页面查看已保存的模型。
4. 在 3D 视口拖拽旋转、滚轮缩放、右键拖拽平移，双击或点击“重置视角”居中。底部可切换线框和原图对照。

独立生成不会绑定部件、跳转部件编辑器或修改场景。悬浮队列通过“展开 / 收起”切换，选择任务或切换标签不会重置展开状态。选中任务后，右侧属性栏只读展示任务状态、生成参数和模型信息；左侧回显所选模型的原图缩略图及尺寸，可直接使用该图再次生成。生成参数保留用户当前输入，不会被历史任务回填。

目标三角面数、随机种子和模型采样参数按部件或输入图片独立保存。在当前素材里修改参数不会改动其他素材或全局默认值；新素材从设置中的默认参数开始，替换输入图片会创建独立参数。部件参数保存在当前浏览器中，关闭面板或刷新后仍可恢复；场景中的快捷生成也使用该部件的参数。已提交任务保留提交时的参数快照。

重置按钮始终与参数原始默认值比较：目标三角面数为 12000、随机种子为 12345，采样步数和网格提取分辨率采用当前生成算法声明的默认值（当前为 5 和 256）。当前值不同时显示按钮，悬停可查看恢复目标；点击后恢复原始默认值。自定义初始化设置、素材保存值和历史生成参数都不会成为重置基准，旧版本保存的独立基准会被忽略，已有参数和生成记录仍保留。

## 在编辑部件时使用

在“场景光影”或“精灵图切分”的部件编辑器中，展开几何下拉菜单，点击首项“＋ 生成模型”。参数、进度和 3D 预览都在当前页面完成；任务同时托管到模型生成队列。关闭生成面板不取消任务，重新打开同一部件可找回关联记录。

预览满意后点击“应用到此部件”，仅替换当前部件草稿的几何，保留名称、法线和对齐参数；再保存部件完成修改。生成失败不会覆盖旧模型，源图改变后也不会应用旧图的生成结果。保存的部件网格可离线使用。

建议保留默认的 5 步采样和 256 网格分辨率。花瓶实测中，仅将采样改为 1 步就出现严重变形，且网格提取更慢；任务成功、GLB 非空不代表生成质量合格。

单张图片无法保证还原真实几何，瓶口、椅子间隙和不可见表面可能被填充。生成完成后仍需人工检查；实际样例与已验证平台见[验证记录](../history/model-generation-validation.md)。
