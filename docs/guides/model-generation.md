# 使用模型生成

本页说明连接服务、生成模型与采用结果。[文档索引](../README.md) · [后端配置（EN）](../../services/generation-python/deployment.md)

## 选择运行方式

| 场景 | 启动方式 |
| --- | --- |
| 查看内置 AI 模型和图片 | 在线体验或 `npm run dev:web`，无需后端 |
| 本机网页与 AI | 安装前端依赖后运行 `npm run dev` |
| 已有网页，只启动 AI | `npm run dev:gensvc` 或 `sh start-generation.sh` |
| 没有后端源码 | 在连接设置中复制安装命令，到生成设备的终端执行 |

首次 AI 启动会准备运行环境和约 4.23 GB 的默认模型权重。已有资源会复用；首次准备不要加 `--offline`。国内网络可先执行 `npm run setup:cn`。Windows 的 `sh` 命令使用 Git Bash；npm 命令也可在 PowerShell 执行。

使用 CPU 可添加 `--cpu`，NVIDIA CUDA 添加 `--cuda`，Apple Silicon MPS 添加 `--mps`。例如 `npm run dev:gensvc -- --cpu`。平台范围与更多模型见[设备配置](../../services/generation-python/deployment.md#gpu-and-platform-support)。

## 连接服务

1. 启动后端，参数表会显示 API 地址和首尾各 4 位、中间以 `*` 遮盖的访问凭证，短凭证全部遮盖。凭证行的备注和启动日志中的 `[访问凭证]` 说明均提供一行 Shell `cat` 命令（Windows 使用 Git Bash），读取配置文件后复制 JSON 中 `token` 字段的值。路径会随实际数据目录配置变化。
2. 打开 **设置 → 模型生成 → 连接服务**，填写 API 地址和访问凭证。
3. 点击“测试连接”，查看实际设备、模型启用状态与错误信息。本机和远程服务均需手动填写对应凭证，不会根据地址自动获取凭证。
4. 选择已启用模型。加载中可以提交排队任务，取消排队不会中断模型公共加载。

安装引导默认折叠，点击标题展开或收起，不随 API 地址输入变化。未配置地址时，网页不主动探测本机服务。模型加载失败需处理原因并重启后端；测试连接只刷新状态。任务失败后可手动重新提交，服务不会自动更换设备或模型。

修改 API 地址会立即清空旧凭证；修改地址或凭证后，后台检测暂停，点击“测试连接”后恢复。连接信息仅保存在当前浏览器中，重新打开页面可恢复已保存的地址和凭证。“允许其他设备访问”只修改安装命令，不会更改正在运行的服务。

## 连接其他设备

在连接设置中勾选“允许其他设备访问”，复制安装命令到生成电脑执行。已有源码时，在项目根目录运行：

```sh
sh start-generation.sh --host 0.0.0.0 --origin https://your-site.example
```

网页填写生成电脑的实际地址，例如 `http://192.168.1.20:8765`，不要填写 `0.0.0.0`。浏览器所在网络必须能够访问该地址；跨域来源、凭证和浏览器本地网络权限也须满足。公网 API 使用 HTTPS，详细说明见[直连访问](../../services/generation-python/deployment.md#direct-access-from-another-device)。

## 生成与查看

1. 进入“模型生成”，选择图片，调整参数并点击“生成模型”。
2. 在视口左上角的任务队列中查看进度、选择任务和查看结果。
3. 完成的模型自动保存在当前浏览器中；后端断开后仍可查看已保存结果。
4. 在效果预览和模型查看之间切换。模型查看用半透明叠加或差异图检查图片匹配；左侧滑动对比查看原生与优化版本。

默认启用 Mini Turbo。Mini 和标准 Turbo 默认 5 步采样，完整 2.1 默认 50 步；先保留模型默认参数，再检查外形与孔洞。生成成功不等于模型正确。

## 在部件中采用结果

1. 打开部件编辑器，在模型菜单中选择已有模型，或点击“＋ 生成模型”。
2. 新生成结果满意后点击“应用到此部件”，更新当前草稿，再保存部件。
3. 模型卡片内“使用优化结果”决定采用原生或优化版本。没有结果时计算一次，开关位置显示加载状态；完成后缓存并自动采用。
4. 左侧滑动对比默认打开。图片叠加和差异图检查真实图片与模型，关闭滑动时检查当前采用版本。

固定图片参考框不随模型变化。重新打开、切换模型或等价图片 URI 不重复优化；输入内容或算法版本变化才需要新结果。失败显示错误并保留原生结果。内置六张图片随附 Mini 模型和预计算结果。

网格提取分辨率默认 128，允许 128–512；目标三角面数默认 40,000，允许 1,000–1,000,000。官方分辨率上限 512、面数上限 1,000,000 来自 [官方界面的可选范围](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/blob/main/gradio_app.py)，不是模型硬上限或每次都应使用的推荐值。高分辨率增加解码资源消耗，高面数增加导入和渲染开销。历史任务及模型重新生成参数保留。旧全局／素材草稿中与旧默认值相同的 12,000 面、256／384 分辨率会一次性迁移到新默认值；其他自定义值保留。旧存储未区分手动输入与默认值，迁移完成后再手动选择旧值也会正常保存。重启生成服务并重新检测连接后可读取新的范围和默认值。


Mini／标准 Turbo 的分层解码若在粗网格上找不到待细化表面点，会使用同一份形状数据、同一设备和精度，在请求的分辨率下分块完整采样。该路径可提取被粗网格漏掉的薄板，不会换种子、增厚或重塑模型；正常路径仍使用 FlashVDM。完整采样仍无表面时报告明确失败，显存错误和取消会正常传播。完整采样的体积网格保存在 CPU，GPU 查询按块执行。

生成模型时，可直接在生成参数顶部的模型下拉框中选择已启用的 AI 模型，无需返回设置。选择会记住为当前模型；每种模型的采样参数分别保留，切换不改变已提交任务的模型记录。提交期间暂时禁用模型选择。


当前模型检查与优化选择以 [模型交互设计](../design/model-comparison.md) 为准：左侧控制滑动，模型卡片选择原生/优化，叠加和差异图比较图片与模型。

生成流程中的“生成后优化模型”默认开启；开启时优化属于任务完成前的步骤，关闭时跳过。任务完成后打开任何视口均只读取已存结果，不触发优化。内置六个物品的优化结果随安装资源提供。
