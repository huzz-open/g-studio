# 部件与场景光影

返回[文档索引](../README.md)。本页介绍当前编辑操作；数据格式和渲染原理分别见[部件参考](../reference/parts.md)与[光照参考](../reference/lighting.md)。

## 从精灵图创建部件

1. 在切图工具中导入精灵图，完成自动检测或手动切分。
2. 双击精灵或选择“编辑部件”，打开共享部件编辑器。
3. 查看原图、法线或“光照与阴影”，调整法线、几何尺寸和图像对齐。
4. “保存并返回”提交修改；“加入场景”先保存再创建实例。取消则放弃草稿。

切图结果稳定后会登记到部件库。未提供几何的图片默认使用轮廓近似；同一张图片已有生成结果时，“几何”下拉框会优先列出“已生成模型”，首次自动采用最新可用模型。手动选择后会保留选择，也可通过[模型生成](model-generation.md)生成新模型。

几何选项包括已生成模型、轮廓近似，以及内置物品自身对应的模板。切换后的模型和尺寸随部件保存，重新打开或导出再导入后仍可切换回来。形状切换保留尺寸及重置基准，仅手动修改参数时显示对应重置按钮。

展开几何选择后，通过卡片查看各模型、模板和轮廓薄片的自动旋转预览。悬停卡片（或用键盘聚焦）会临时切换主视口中的形体，移开或关闭菜单后恢复勾选项，不修改部件数据。点击卡片才更新勾选项和编辑草稿，菜单保持展开以便继续比较；“保存并返回”只保存勾选结果，不保存悬停预览。无法预览时显示对应图标。关闭选择菜单后停止卡片预览；系统设置减少动态效果时使用静态预览。

同一个部件可被多处引用。保存部件会更新这些引用；每个场景实例的位置、缩放及投射/接收阴影开关独立保留。

## 在场景中编辑

- 从导航进入“场景光影”。部件库支持搜索、添加和拖入；导入部件只加入库，需要另行放入场景。
- 双击实例编辑其部件；返回时保留场景状态。“在精灵图中打开”可定位来源，原图未打开时会打开已保存的裁剪图。
- 标签栏的加号创建空场景；预设打开独立场景标签。双击标签可重命名，关闭的场景可从重新打开入口恢复。
- 左键拖动空白区域平移画布，滚轮缩放；“适应视图”重新取景。选中对象后拖动，或使用方向键移动。

场景左侧控制显示选项，右侧编辑选中实例属性。名称可在场景中开关；单部件预览隐藏名称和选中描边。场景选中反馈使用沿透明轮廓的内描边。

## 灯光与阴影

| 类型 | 调整方式 |
| --- | --- |
| 点光源 | 拖灯图标改变高度，拖地面手柄改变水平位置 |
| 方向光 | 拖球面太阳控件改变方向，赤道手柄调整方位角 |
| 亮度 | 灯图标上使用滚轮或加减键，也可使用参数控件 |

两种灯光保留各自参数。黄色地面手柄用于调整灯光，不是物品选中标记。

可分别关闭实例的投射和接收阴影，也可使用全局阴影开关。几何模式帮助检查实际参与遮挡的形体；图像与几何不吻合时，阴影可能与画面预期不一致。

参数修改后可逐项重置。场景编辑支持撤销/重做；刷新会清空撤销历史，已保存的内容仍可恢复。单部件中的灯光、环境和相机用于预览，不改写原图。

## 导出与备份

| 操作 | 结果 |
| --- | --- |
| 导出资产 JSON | 单个 `.gpart.json`，包含图像和部件参数 |
| 导出部件包 ZIP | `part.json`、`color.png`、`normal.png`；导入时提取 `part.json` |
| 导出场景与部件 | 场景状态和去重后的完整资产，可重新导入 |
| 切图导出勾选“同时导出法线” | 散件附带 `名称_normal.png`；合成图附带同排布法线图 |

浏览器本地保存不是外部备份。需要跨设备或长期保存时，请导出资产或工程。
