# 模型生成服务架构

状态：已接入架构的设计说明，按 2026-10-27 工作区整理。平台实测范围见[验证记录](../history/model-generation-validation.md)。返回[文档索引](../README.md)。

## 职责划分

| 层 | 职责 |
| --- | --- |
| 网页生成客户端 | 提交、查询、取消、校验结果；屏蔽直连与中转差异 |
| 浏览器轮廓算法 | 不依赖服务的近似几何，作为默认方式 |
| Python 服务 | 鉴权、临时任务队列、调度 Provider、返回结果 |
| Provider | 描述能力、准备依赖和模型、执行生成及取消清理 |
| Node/TypeScript 中转 | 设备配对、授权、转发及临时文件传输 |
| 前端资产系统 | 预览、应用、保存网格、修订和场景引用 |

直连路径为“网页 → Python”；中转路径为“网页 → 中转服务器 ↔ Python”。Python 主动建立 WSS 连接，中转服务器无需模型和 GPU。

## 设计决定

- 协议独立于模型和语言；首个 AI 实现为 Hunyuan3D-2mini-Turbo，可添加其他 AI 或纯算法 Provider。
- 生成服务管理临时任务，前端管理长期资产。客户端持久保存后确认接收，临时传输文件可清理。
- 生成成功先预览，再由用户应用；失败不覆盖现有部件。网格嵌入 v2 资产，服务离线后仍可使用。
- 默认开发启动同时运行网页和后端，网页先启动；仅网页开发有独立命令。
- 后端统一使用 sh 入口。项目内保存可复用资源，按系统/架构及 CPU/CUDA 隔离运行时；模型共用。
- 启动验证文件与版本，完整则复用，缺失则补齐；离线检查是显式选项。
- 默认资源与私有数据分开，分发包排除凭证和任务。不同平台分别准备并验证。
- 中转使用设备级授权，10 位大写字母数字配对码直接授权，5 分钟有效且单次使用，无需本机终端确认；不引入公共算力池或账号资产库。

单图生成目前只提供几何，不保证真实结构或隐藏面的语义正确；不包含训练、自动语义修复或从网格还原可编辑基础形体。
