# 原始模型与优化候选的显式选择

状态：已接入。[操作指南](../guides/model-generation.md) · [部件格式](../reference/parts.md) · [文档索引](../README.md)

优化输出是候选，不能以轮廓分数替用户决定采用。部件编辑器展示两个版本的同步滑动对比，同时独立保存当前采用的版本。

## 数据与行为

`PartAsset.modelComparison` 保存原始网格快照及图像显示范围、输入指纹、可选候选和选择状态。`PartAsset.geometry/alignment` 始终是当前实际采用的快照。候选重新计算或手动调整时，只更新比较数据，不改变已采用快照；即使用户之前采用过优化，也需要再次显式采用新候选。

- 新模型默认采用原始生成网格。`original` 渲染分支直接读取 GLB 顶点，不再次按尺寸缩放或按优化参数变换。
- 原始与已采用快照用 `frozen` 标识，后台覆盖生成模型不会将新网格偷偷套进旧参数。
- 原有保存的优化或尺寸调整作为历史候选保留其现有效果，不自动重新运行算法。
- 输入图片或模型源版本变化时，候选失效、采用按钮禁用。现有采用结果保持；用户可显式重新选择最新模型。
- 取消或计算失败保留旧候选。实体检查不通过的“修复”只显示原因，不生成一个假装修复成功的新版本。
- 保存/导出携带原始、候选与已采用快照。内置图嵌入 PNG 后更新等价图片指纹；原始 GLB 不变。

## 同步对比

两个生产 LightingViewport 使用同一个 SceneState。右侧用 CSS clip-path 裁切完整画布，分隔线不会改变画布大小、相机矩阵或模型。分隔线默认 50%，支持拖动和键盘操作。仅两侧都完成资产更新后展示比较，避免将新旧异步帧混作结果。

联合取景同时包含两个版本，不能各自居中或缩放。原始与候选同场景位置、灯光、地面及法线设置。几何模式的检查相机可以旋转；图片光照模式保持其校准相机，以免把固定投影图误当作任意视角纹理。平移和缩放共享；改变分隔线不会改变选择状态。

## 验证入口

单元测试覆盖默认原始、候选写入不影响采用、重复计算、显式切换、序列化、旧数据保留、源更新失效、快照固定与联合取景。浏览器检查覆盖以下行为；已有真实生成素材时检查真实结果，否则只验证通用 UI 流程：

- 打开时没有启动优化 Worker；计算完成后仍采用原始模型。
- 左右画布尺寸一致；拖动分隔线后两张底层渲染缓冲不变。
- 几何旋转同时更新两侧。
- 保存重载保留两个版本和选择。
- 取消、模拟失败、不支持的修复均不切换当前版本。
- 再生成来源更新后，旧候选禁止采用，已采用网格保留。

入口为 `tests/model-comparison.e2e.cjs`，旧 `tests/image-fit-ui.cjs` 转到此流程。已有本地真实椅子报告时使用真实素材；干净环境使用通用 UI 测试网格，不将其当作真实生成效果验证。独立模型生成查看器继续展示原始结果，优化候选属于部件及其图像对齐设置。
