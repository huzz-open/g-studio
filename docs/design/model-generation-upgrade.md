# 多模型推理服务设计

状态：三模型接入、常驻执行与队列机制已实施；数值根因、性能和几何质量仍有开放问题。

[服务架构](model-generation.md) · [后端配置](../../services/generation-python/deployment.md) · [原始方案快照](../history/model-generation-plan-20261028.md)

## 目标与范围

在同一几何生成协议下提供 Mini Turbo、标准 Turbo 和完整 2.1 Shape，分离 HTTP 可用性、资源准备与模型就绪状态。生成结果进入现有部件资产流程。

本设计限于几何生成。纹理、PBR、2.1 Small、多视图生成和额外推理后端不在本次接入范围内。模型规格与定位标签不能保证单张素材的质量排序。

## 模型与资源

| 模型 | Provider ID | 默认采样步数 | 资源关系 |
| --- | --- | ---: | --- |
| Mini Turbo | `hunyuan-mini` | 5 | Mini 形状网络与 512-token Turbo VAE |
| 标准 Turbo | `hunyuan-turbo` | 5 | 标准形状网络与 3072-token Turbo VAE |
| 完整 2.1 Shape | `hunyuan-2-1` | 50 | 完整 checkpoint 内的网络、VAE 与 conditioner |

默认只启用 Mini；其他模型由启动参数显式启用。模型版本、大小与 SHA256 在各自清单中固定，2.0/2.1 使用独立源码 wheel。镜像只替换下载来源，不能替换配置或校验规则。详细来源见[附带资源](../../services/generation-python/bundled/README.md)。

## 执行与容量

- 启动时确定设备、精度、启用集合和策略。默认 `resident`，旧 `auto` 兼容为常驻；只有显式 `staged` 使用分阶段加载。
- 常驻模型后台加载并进行有界预热，后续请求复用实例。分阶段模式按任务加载、释放对应计算阶段。
- 内存估算只用于诊断，不阻止加载或任务，不自动更改策略。实际分配、初始化或推理错误使对应模型或任务失败。
- 执行错误不自动更换设备、模型、精度或策略。自动设备探测与执行期回退是不同机制。
- 输入预处理固定为 CPU FP32；模型计算使用启动选定设备。Mini/MPS 图像编码固定 FP32，其余采样和解码遵循配置精度。

容量策略实现见 [policy.py](../../services/generation-python/policy.py)。历史方案中的容量准入和自动 staged 选择已被上述规则替代；历史阈值不是硬件最低要求。

## 状态、队列与取消

HTTP 在资源准备、加载与预热期间仍可访问。启用且声明 `acceptsJobs` 的模型允许提交排队；旧服务缺少此字段时，客户端保持 ready-only 行为。

服务允许一个活动任务和八个有效排队任务。并发请求共享模型准备过程；取消排队不取消公共加载。常驻任务在编码块、采样步、解码块及减面边界检查取消，分阶段任务终止自己的进程树。

加载失败结束受影响的排队任务；服务重启后未完成任务保留中断语义。完整状态字段、标签、计时和错误约定见[生成协议](../../packages/generation-protocol/protocol.md#loading-residency-and-timing)。

## 日志与验证

启动日志展示实际设备、后端、精度、模型及策略。任务分别报告排队、执行和总耗时，失败与取消也保留计时。模型实例 ID 和加载次数用于检查是否复用；进程内存、设备张量和驱动占用分别报告。

验证需要同时覆盖服务生命周期与真实几何。合法 GLB、有限数值或面数达标不能替代多视角检查。

| 证据 | 范围 |
| --- | --- |
| [2026-10-28 服务验证](../history/model-generation-upgrade-20261028.md) | MPS 三模型、队列、取消、加载与几何对照 |
| [2026-10-28 CUDA 对照](../history/model-generation-cuda-20261028.md) | RTX 3060 上固定上游与项目路径，分别常驻的真实生成 |
| [Mini 调查](mini-inference-investigation.md) | MPS FP16 根因、耗时分解和容量测量的开放问题 |

Mini/MPS 的 FP32 编码是规避办法，根因仍未关闭；完整 2.1 的盆景退化也未解决。多模型同时常驻、其他设备与长期运行需要独立验证。进一步模型实验按已有阶段决定暂停，本文整理不改变该状态。
