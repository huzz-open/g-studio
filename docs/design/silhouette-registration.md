# 无 AI 的三维模型与图片轮廓配准

## 可见表面保护（surface-preserving-v2）

实际光照验证发现仅看轮廓会把伞底当成伞面。当前版本在相似变换搜索后增加通用的可见表面先验，不读取物体类别，也不限制俯仰/朝向角度。

用 128×128 Z-buffer 记录每个像素最近的源三角形，再以三角形实际面积乘可见比例估计源表面分布。比较参考姿态与候选姿态的归一化分布交集。只有保留度至少 0.65 的候选才能自动应用。该阈值是统一的保守工程策略，不是从图片恢复三维朝向的数学证明。Z-buffer 依据见 [Khronos 深度测试说明](https://wikis.khronos.org/opengl/Depth_Test)。

精化所有保留下来的起点，而不只精化轮廓排名前三；另外求解固定参考角度下的尺度和平移作为安全候选。若不受约束的最佳轮廓候选比可自动采用的结果损失低超过 0.025，显示“请检查几何视图”的提示。候选仍可在完整 SO(3) 上搜索，但明显换面的结果不能仅凭更高 IoU 静默应用。对原本朝向错误、需要大幅换面的模型，可能需要用户先指定正确可见面；界面保留手动旋转。

参考是输入模型的既有可见面，不是对原图的语义识别。重复自动拟合沿用保存的参考，避免累积漂移。旧 v1 的自动角度不作为新先验；明确的手动角度修改保留，模型源哈希变化则重新从新源姿态建立参考。下面的轮廓目标和搜索数学仍然适用，最后的自动接受规则以本节为准。

本实现把模型与图片匹配定义为正交相机下的三维相似变换估计，不根据素材名称、provider、物体类别或内置示例选择算法参数。原图 alpha 是目标前景；投影使用场景同一组 `RIGHT/UP` 相机基向量。

## 变换模型

对已经采用用户指定尺寸的网格，求解 `p' = s R p + t`。`R` 是三维旋转、`s > 0` 是全轴统一缩放、`t` 是平移。观察到的参数是旋转三自由度、尺度一自由度及图像平面平移两自由度。正交投影无法确定视线方向平移，因此用最低点落地约束确定剩余自由度。

图片显示范围固定，模型去匹配图片。包围盒仅提供初始尺度与中心，不作为最终匹配标准。默认保持模型比例；用户之后手动修改宽高深属于显式编辑，不是自动算法猜测。早期分别拉伸宽高的记录仅保留读取兼容，编辑器会重新校准为相似变换。

## 目标函数与搜索

目标函数为 `0.7 × (1 − IoU) + 0.3 × symmetricChamfer`。IoU 比较整个前景区域，Chamfer 比较双向轮廓距离，以评价网格对角线归一化。外边缘与孔洞边缘使用同一规则。距离变换采用八邻域权重 `1 / sqrt(2)`，是离散欧氏距离的近似，不是精确欧氏距离或 Hausdorff 最大距离。

1. 使用 Shoemake 单位四元数参数化，将确定性的 Halton 低差异序列映射到完整 `SO(3)`。使用 192 个样本及坐标轴基准姿态；没有直立、朝前等类别假设，也不限制物体俯仰与倾斜范围。
2. 在 48×48 网格上初选，保留六个旋转不同的起点，并加入当前姿态作为独立起点。
3. 在 80×80 网格上对每个起点执行标准 Nelder–Mead：反射 1、扩张 2、收缩与缩小 1/2。局部旋转使用指数映射增量，避免直接优化欧拉角时的奇异点；其余变量为对数尺度和归一化平移。
4. 最好的三个结果在 160×160 网格上继续细化，与同分辨率的原姿态比较。仅接受目标函数改善且 IoU 不低于基线的结果；目标改善不足 0.002 时保留基线。

局部数值搜索域为相对包围盒初始尺度的 log 修正 ±0.4、目标宽高归一化平移 ±0.25。评价画布外围留 12.5% 空白，计入越出目标轮廓的投影。所有模型使用同样的分辨率、权重、搜索预算和边界。多起点局部优化不宣称求得数学上的全局最优。

软件扫描转换使用全部三角形的投影并集，不抽掉小三角形，也不剔除背面。图像阈值与实际渲染一致，四点采样用于低分辨率遮罩。算法在可终止的 Worker 中执行，结果写入草稿前检查源数据是否改变；取消不改变草稿。保存的是参数和方法版本，原始 GLB 不变。

## 结果使用与验证

场景、部件预览、表面深度/法线烘焙和阴影投射共用校准后的顶点及三角形。法线执行对应逆转置变换。模型来源更新后，编辑器重新估计姿态；手动角度和尺寸修改后不展示过期匹配分数。

验证不只比较一张示例的视觉效果：

- 用独立的重心坐标光栅器生成已知姿态图片，检查搜索后的轮廓误差。
- 覆盖椅子孔洞、分枝、薄面、旋转对称体、横放和倒置姿态，以及临时生成的不具类别名称的组合几何。
- 检查等比缩放保持任意顶点对距离比，避免以形变换取重合分数。
- 独立验证优化器的耦合二次函数收敛，以及 Chamfer 的对称性和孔洞响应。
- 检查位置、法线、阴影三角形、落地、保存重载和手动调整；浏览器验证取消不写回与 Worker 正常结束。

单视图轮廓配准的结果是符合该视图的几何姿态。对称几何的不同姿态可具有同样投影，因此界面将数值称为“轮廓重合度”，不将它解释为三维重建可信度。

## 理论与实现参考

- Shoemake, *Uniform Random Rotations*, Graphics Gems III (1992)：[Graphics Gems 原始代码与索引](https://github.com/erich666/GraphicsGems)。本项目将随机输入替换为确定性的低差异采样，使用同一四元数参数化。
- Nelder–Mead 无导数单纯形优化：[SciPy 方法说明](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-neldermead.html)。项目在 TypeScript 中实现标准系数版本，不依赖 Python 服务。
- 二值图距离变换：[OpenCV distanceTransform](https://docs.opencv.org/4.x/d7/d1b/group__imgproc__misc.html)。项目实现八邻域近似距离场，用于双向平均轮廓距离。

这些是独立的成熟数学工具；本项目的组合目标、预算和接受准则是工程选择，由回归测试验证，不声称来自一个已经证明能还原任意物体的算法。
