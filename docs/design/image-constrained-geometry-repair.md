# 原图约束的几何修复

**当前执行版本为 repair v2。** 已修正奇偶交点配对、降采样及冷同步重建问题，详见[审查修正记录](../history/repair-review-fixes-20261029.md)。当前要求实体条件检查通过，使用非零绕数区间合并；不确定则整体保留源几何。原生像素预算为 1,048,576，不有损降采样。修复后保持原支撑高度。实际渲染的冷重建通过 Worker 完成；v1 记录可读取但不再自动应用。

修复针对已对齐的生成网格，运行在浏览器 Worker 中，不调用 AI，也不按资产名称、类别或 provider 分支。原始 GLB 保留；`geometry.repair` 保存遮罩、图像平面范围及源数据指纹，重建的是场景使用的几何代理。深度烘焙、法线、可见几何和阴影投射共用这些三角形。

## 必须先区分真实孔洞

孔洞不等于错误。实际椅子 PNG 的镂空花纹就是透明区域，普通网格补洞不能决定它们是否应该封闭。本算法以与着色器一致的 alpha ≥ 21/255 为可见前景。透明区域始终保留为空隙；只有不透明区域中的几何缺失才可能补齐。

## 通用算法

1. **轮廓挤出约束。** 将二维前景沿正交相机视线挤出。生成网格与此约束相交，去除投影落在透明区域或图像外的几何。这是 silhouette volume 的单视图约束，不宣称恢复完整多视图 visual hull。
2. **实际三角形裁剪。** 前景按扫描线拆成不重叠矩形，逐个用 Sutherland–Hodgman 半平面裁剪三角形；交点插值原位置、法线和颜色。积分图快速保留完全处于前景的三角形，不把整个模型重建成平面。
3. **保留深度分层。** 先检查精确位置索引下的闭合性、边方向和壳方向。轮廓切口根据有方向射线交点的非零绕数区间构造侧面，合并重叠实体且保留分离层间的空气。重复命中按连通分量去重；切口区间无法确认时放弃整次修复，保留原几何。
4. **局部缺口补齐。** 在前景中找到没有几何深度的连通分量。仅处理面积不超过前景 2%、到已知深度的前景内距离不超过网格长边 1.5%、边界前后深度变化不超过几何尺度 15% 的小缺口。大缺失、远离现有表面的缺失、跨越明显深度断层的区域保持未修复。
5. **调和深度插值。** 已知边界深度固定，在缺失区域求离散 Laplace 方程，分别补前后深度，构造前后表面。真实 alpha 孔洞不参与求解，表面补片最多延伸一格到已有表面以连接边界。

遮罩使用原图分辨率，工作预算为 1,048,576 像素；超预算拒绝，不通过删除混合格中的细结构来减少工作量。本次两个真实输入在预算内，但原文件不满足实体封口条件。派生网格最多 250,000 三角形，超限报错且不替换草稿。所有参数与对象类别无关。

这是面向固定相机图像的几何约束，局部补片和切口连接不承诺全局水密流形，也不作为已经验收的碰撞体。未改变背面且与轮廓不矛盾的原始结构继续保留。高精度碰撞或制造网格仍需独立的拓扑检查。

## 状态与使用

部件编辑器先完成对齐，然后点击“按原图修复几何”，可用“启用几何修复”开关比较。取消、失败或源数据变化不会把旧计算写回。尺寸、朝向、锚点、图片内容或源网格变更后，旧修复失效并提示重新计算。名称和法线细节修改不使几何修复失效。

保存/导出的部件携带修复参数与原 GLB，可离线重建。内置图转为嵌入 PNG 时仅更新等价图片的缓存指纹；未修改原图像素。独立模型查看器仍显示原始生成模型。

## 依据与验证

- Sutherland / Hodgman, *Reentrant Polygon Clipping*, CACM 17(1), 1974，[论文 DOI](https://doi.org/10.1145/360767.360802)。本实现使用其半平面裁剪方式。
- Laurentini 的 silhouette volume / visual hull 约束：[作者论文](https://cgvg.polito.it/Articles/cvpr93.pdf)。本实现只使用单图挤出约束，不声称能恢复不可见真实结构。
- 深度补齐使用固定边界的离散调和方程；这是本项目实现的局部插值，不是调用通用网格库后宣称“所有孔洞已修复”。

回归测试覆盖真实透明孔洞保留、虚假小孔前后封面、多余几何裁剪、深度断层拒绝、源三角形不变、阴影/可见顶点一致、参数变化失效和保存重载。真实素材结果见[验证记录](../history/image-constrained-repair-20261029.md)。
