# 共享编辑器与计算

当前组件约定，核对基准：2026-10-27 工作区。返回[文档索引](../README.md)。

## 外壳与标签页

`EditorShell`、`ShellTabBar`、可调整侧栏和 `useEditorTabs` 提供共享布局。场景标签各有内容、选择、灯光和撤销历史；标签和最近关闭场景保存到本地。旧单场景保存迁入第一个标签。

`ScrollArea` 保留原生滚轮、触摸和键盘滚动，覆盖式滚动条支持拖动、轨道翻页和 Home/End/PageUp/PageDown。诊断信息默认折叠。

## 历史边界

`EditorShell.history` 接受 `HistoryController`，连接标签栏撤销/重做和 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Y。文本输入保留原生撤销，模态框阻止背景历史操作。

`createHistoryStack` 提供快照/事务，`createObservedHistory` 适配可序列化状态。一次拖动或连续按键手势记录为一步；过期编辑者的延迟提交被忽略，新修改清空重做。

| 操作 | 历史行为 |
| --- | --- |
| 场景对象、灯光、房间和显示参数 | 进入当前场景历史 |
| 选择、缩放和平移 | 导航状态，不消耗对象编辑历史 |
| 文件读写、资产修订、标签创建/关闭 | 不由场景快照撤销；关闭标签有独立恢复入口 |
| 刷新或关闭标签 | 重置内存撤销栈，保留已保存内容 |

切图和区域编辑保留各自文档快照；瓦片参数使用共享观察历史，地形绘制使用其独立绘画历史。

## 参数与后台计算

共享输入控件用 `update:modelValue` 即时更新显示，用 `commit` 表示松手或确认后的最终提交。`createLatestTask` 支持即时、节流、防抖、提交后计算及自适应间隔。

参数驱动的切图、去背、PNG 和瓦片生成使用 Worker；法线预览复用任务调度。过期任务不能覆盖最新结果，轻量属性即时更新。

`ParameterReset` 为已修改的字段显示重置入口及默认值提示。默认值来自场景创建、部件工厂或内置模板，不随用户保存的修改漂移；重置参加相应编辑历史，忽略 Float32 表示噪声。

## 部件预览更新

几何更新在后台准备后按当前批次发布。失败或被替代的批次保留已有可用预览；参数变化不重新取景。首次加载自动取景，用户可显式选择“适应视图”。
