# 光照渲染参考

当前实现核对基准：2026-10-27 工作区。[操作指南](../guides/parts-and-lighting.md) · [文档索引](../README.md)

## 共享渲染路径

场景与单部件预览共享 [LightingViewport.vue](../../src/modules/scene-lighting/LightingViewport.vue) 和 [renderer.ts](../../src/modules/scene-lighting/renderer.ts)。正交相机使用固定俯仰/方位角，平移和缩放不改变视角方向。

场景保存房间尺寸、灯光类型及各自参数。旧数据补默认值；房间坐标和几何细节见 [model.ts](../../src/modules/scene-lighting/model.ts)。

## 灯光与阴影

| 类型 | 阴影与衰减 |
| --- | --- |
| 点光源 | 六面径向深度 cubemap，按距离平方衰减 |
| 方向光 | 正交阴影图，固定入射方向和强度 |

两者使用相同的几何、接收面和投射/接收开关。方向光由方位角与仰角定义，不通过远距离点光源模拟。PCF 用于过滤锯齿，不代表面积光源的物理软阴影。

## 图像与几何

像素图作为面向相机的裁片渲染。从部件几何烘焙前表面深度和法线，覆盖像素据此重建位置、接收阴影并写深度；原法线图提供细节变化。未被几何投影覆盖的像素使用平面近似。

轮廓、内置模板与生成网格都可能和原画不完全一致。几何视图显示实际遮挡假设；法线图不能恢复隐藏结构或修复几何轮廓。渲染不修改原图。

生成网格采用部件级三维相似变换配准：`alignment.height` 固定图片显示高度，`geometry.imageFit` 保存基准尺寸、目标矩形、旋转和投影平面的缩放/平移修正。`mode: similarity` 使用全轴统一缩放，避免宽高独立拉伸；沿视线平移恢复地面接触不改变正交投影。后续尺寸编辑相对于校准基准生效，法线使用逆转置变换。可见几何、表面烘焙和投射阴影共用同一变换。无 `mode` 的旧校准仍能读取，在部件编辑器中升级；模型替换后编辑器依据新网格重新搜索。算法细节及来源见[轮廓配准设计](../design/silhouette-registration.md)。

木箱迎光边缘暗条的历史调查见[调查记录](../history/shadow-alignment-2026-10-26.md)。该记录没有确认灯光方向错误，也没有实施只针对木箱的遮罩修复。

## 状态与缓存

几何和图像对齐变化会重建表面缓存；旧批次失效后不能覆盖新结果。灯光调整更新渲染状态，部件几何更新保留用户的相机、灯位及预览姿态。

场景名称开关与自动选中描边分开处理；单部件视图隐藏名称和描边。旧选中显示设置在加载时忽略。

## 独立验证页

`#/experiments/umbrella-shadow` 使用手工设定的伞面和伞杆检查几何投影。它不从 PNG 自动重建，也不是当前部件编辑器的另一套实现。

数学与浏览器检查入口见[开发指南](../../CONTRIBUTING.md#验证改动)。比较图像和几何模式时保持相机、灯光一致，并分别检查点光源与方向光。诊断采样计数不是屏幕像素面积或帧率基准。
