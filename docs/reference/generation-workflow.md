# 模型生成与采用规则

当前前端行为参考。[操作指南](../guides/model-generation.md) · [部件格式](parts.md) · [文档索引](../README.md)

## 生成记录

独立生成结果保存在当前浏览器，不自动绑定部件或修改场景。服务断开后仍可查看已保存模型。任务属性记录提交时的完整模型名称和参数，切换当前模型不会改写历史记录；覆盖生成成功后才更新对应模型信息。

选中历史任务时，右侧只读展示任务状态、参数和模型信息，左侧回显原图及尺寸。生成参数保留用户当前输入，不被历史参数覆盖。任务队列的展开状态不随选择任务或切换标签重置。

## 参数作用域与重置

目标面数、种子和采样参数按部件或输入图片独立保存，关闭面板或刷新后恢复。新素材从设置中的默认参数初始化，替换输入图片创建独立参数。场景快捷生成使用对应部件参数，已提交任务保留提交时的快照。

重置始终恢复参数原始默认值，不以用户设置、素材保存值或历史任务为基准：

| 参数 | 默认值 |
| --- | --- |
| 目标三角面数 | 12,000 |
| 随机种子 | 12,345 |
| 采样步数 | 由模型能力声明；Mini/标准 Turbo 为 5，完整 2.1 为 50 |
| 网格提取分辨率 | 由模型能力声明；上述模型均为 256 |

参数偏离默认值时显示重置按钮及恢复目标。旧版本保存的独立重置基准不再使用，已有参数和生成记录保留。接口声明见[生成协议](../../packages/generation-protocol/protocol.md#request-and-lifecycle)。

## 部件草稿

部件编辑器中的任务由模型生成队列托管，关闭生成面板不会取消任务，重新打开同一部件可找回记录。

“应用到此部件”更新当前草稿，保存部件后才提交到资产库。失败不覆盖旧模型，源图变化后不应用旧图的生成结果。已保存网格可离线使用。

## 原始模型与候选

新生成模型默认使用原始网格。打开编辑器不会自动校准；用户点击“生成优化候选”后才在后台计算尺寸、朝向和位置。

| 事件 | 行为 |
| --- | --- |
| 候选计算成功 | 更新候选，当前采用版本不变 |
| 选择原始或优化结果 | 更新当前草稿采用的快照 |
| 再次计算候选 | 保留已采用快照，需再次显式采用新结果 |
| 取消、失败或修复不受支持 | 保留已有候选和选择 |
| 图片或模型源版本变化 | 旧候选禁止采用，已采用快照保持 |
| 保存或便携导出 | 携带原始、候选及已选版本 |

旧数据保留已经保存的几何效果，不因打开编辑器而重新计算。数据结构与状态转换见[候选选择设计](../design/model-comparison.md)。

## 同步对比

原始与候选使用同样大小的画布、相机、灯光、地面和场景位置，按两者联合范围取景。竖直分隔线只改变显示范围，不影响画布尺寸或采用状态。

几何模式同步旋转；右键或 Shift 拖动同步平移，滚轮同步缩放。图片光照模式保持固定投影视角。分隔线支持拖动、方向键、Home/End 和 PageUp/PageDown。

## 校准与修复边界

轮廓校准默认保护输入模型既有的可见表面。最佳轮廓匹配需要显著换面时，算法保留保守候选并提示检查几何视图；它不修复孔洞或隐藏结构。详见[轮廓配准设计](../design/silhouette-registration.md)。

原图约束修复只作用于已对齐的候选，保留原 GLB 和原图透明孔洞。图片、模型、尺寸或对齐改变使修复失效，需要重新执行；名称和法线细节修改不使修复失效。

repair v2 先检查封闭有向实体条件；检查不通过、切口不明确或超过预算时保留原几何，不提交部分裁剪。工作预算为 1,048,576 原生像素，不隐式降采样。旧 v1 修复可读取但不再自动执行。成功结果仍需显式采用，详见[几何修复设计](../design/image-constrained-geometry-repair.md)。

单张图片不能保证还原真实几何。模型生成、轮廓改善或修复成功都需要人工检查，也不等同于碰撞体已验收。实测条件与质量限制见[历史记录](../history/README.md)。
