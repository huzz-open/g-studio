## 两份真实生成网格

| 项目 | 油纸伞 | 靠背椅 |
| --- | ---: | ---: |
| 旧轮廓最优候选保留原可见面 | 5.86% | 85.13% |
| 本轮自动采用候选保留原可见面 | 66.85% | 85.13% |
| 本轮优化网格轮廓 IoU | 93.12% | 92.14% |
| 实际 GPU 几何覆盖率 | 96.93% | 96.99% |

伞采用约 `[8.25°, -2.38°, -3.58°]`，不再采用旧的 `[-43.78°, -24.07°, 26.78°]`。在相同两组点光源和一组方向光下复验，几何视图恢复为伞面可见；受光不再呈现旧错误姿态的大面积变暗，地面阴影也不再呈现由伞底朝向导致的扁斜形态。

点光源下，伞图像区域关闭阴影后的平均 RGB 从旧错误结果的 88.70 恢复到 111.49，原始未校准为 109.43。受阴影开关影响的像素比例从旧错误结果的 37.42% 变为 13.50%。这些数值仅解释变化，不是“越亮越正确”或“阴影越少越正确”的验收准则。

椅子的最终候选不变，错误孔洞也没有被修复。当前结果解决了这两例中的可见面翻转回归并减少几何覆盖缺口；不宣称几何拓扑错误或所有光照误差都已消除。
