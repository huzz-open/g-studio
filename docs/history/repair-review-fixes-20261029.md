# 几何修复审查后的通用缺陷修正

2026-10-29。本轮处理封口的实体判定、源信息保留、支撑约束和冷加载计算路径。没有对象名称分支，没有为椅子或伞设置不同参数。

## 修正

1. **封口内部判定。** 新版 repair v2 先按精确位置焊接拓扑索引，检查边的邻接数、方向一致性及壳方向。对方向一致的闭合实体并集，射线采用有方向的进出计数和非零绕数区间；重叠区域合并，分离层间的空气保留。共享三角形边造成的重复命中按连通分量去重，不能全局两两配对。近乎平行的面按三维面积和像素尺度归一化判断，防止 Float32 误差制造伪交点。
2. **无法确定时不提交。** 开边界、非流形边、方向不一致、混合壳语义，以及无法对应的切口区间，都保留原几何并返回明确状态。尝试过程不以部分裁剪结果覆盖输入。这里只验证当前运算需要的拓扑及局部交叉条件，不宣称做了完整自交检测或制造级实体认证。
3. **原生分辨率。** 不再把“混合前景/背景格”直接当作透明删除。修复使用原始像素；工作预算为 1,048,576 像素，超预算明确拒绝，不隐式降采样。一像素细杆和一像素孔洞都被保留。
4. **支撑高度。** 支持的修复完成后，沿相机视线平移到输入网格的最低高度。这样保持正交投影，也保持原有支撑高度；不会把原本悬空的资产强行压到地面。
5. **异步冷重建。** 实际场景和几何卡片在缓存未命中时，将解码、源变换和修复放入 Worker，完成后才提交 GPU 几何；取消或过期结果不能覆盖当前视口。同步取景/移动使用轻量边界缓存，冷状态不触发修复。网格缓存淘汰后仍保留较小的边界缓存。
6. **导入额外缺陷。** GLB 导入原来复用了模板生成器的固定面积阈值，误删有效小三角形。现在导入保留非零面积面；CPU 验证射线的平行判断也改为相对尺度判断，避免单位缩小时把所有小面误判成平行。
