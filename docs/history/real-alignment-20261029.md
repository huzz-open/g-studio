## 方法

校准前模拟生成网格应用到对应部件的旧行为：采用 GLB 包围盒尺寸，保留原部件图像锚点。继承的模板仅提供图像与锚点设置，网格顶点全部来自生成 GLB。

然后分别执行当前代码的等比尺寸校准，以及尺寸、朝向、位置联合校准。没有重新生成素材、没有为样例更改搜索参数。三组结果使用相同 `RIGHT/UP` 正交相机、图像位置和显示比例。

评价采用独立的 Pillow 多边形扫描转换，在 1024×1024 公共视域内比较模型投影与 PNG alpha（阈值 0.08）。视域包含所有阶段模型投影，图片外多出的模型计入并集。该评价不复用优化器自己的低分辨率光栅器，因此数值与界面优化分数略有差异。

## 结果

| 物体 | 校准前 IoU | 仅等比尺寸 IoU | 联合校准 IoU | 原图覆盖率：前 → 后 | 搜索时间 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 油纸伞 | 71.5% | 67.1% | 93.8% | 72.8% → 97.9% | 2.25 s |
| 靠背椅 | 78.0% | 85.4% | 89.6% | 92.8% → 97.1% | 2.13 s |

油纸伞的主要改善是伞面投影厚度与下边缘；仅调整尺寸反而降低该例重合度，说明包围盒匹配不等同于轮廓配准。联合校准后边缘仍有小幅外溢，伞柄底部也未完全一致。

椅子外框、椅脚位置和空隙对齐有所改善，但生成网格在靠背纹样处有原图不存在的孔洞，腿部和横撑附近仍有额外模型。这些是形状/拓扑残差，不能由相似变换消除。此轮仅验证该视角的模型投影，不把轮廓分数解释为不可见结构或其他视角的正确率，也未据此宣称光照问题全部解决。

## 产物与复现

本地结果保存在忽略目录 `output/alignment-real-20261029/`：

- `umbrella-comparison.png`、`chair-comparison.png`：原图、校准前、尺寸校准、联合校准；下排为误差分布。
- `inputs.json`：实际来源路径、输入及 GLB SHA256、提供者与参数。
- `report.json`：相机、校准参数、耗时及独立评价指标。
- 各阶段 `.f32` 文件为实际渲染顶点的位置，原素材未改动。

有本地输入清单与 RGBA 文件后执行：

```sh
node scripts/verify-real-alignment.cjs output/alignment-real-20261029/inputs.json
python scripts/render-alignment-report.py output/alignment-real-20261029
```

Python 需要 Pillow 和 NumPy。私有任务目录、原始生成输出和大图不纳入 Git；本报告记录已观察到的结果和边界。
