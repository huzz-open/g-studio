# trial-01：三件像素游戏光照代理模型

本目录只根据 `inputs/umbrella.png`、`inputs/vase.png`、`inputs/chair.png` 三张参考图建立简化的三维代理模型。目标是给像素游戏的光照、阴影、遮挡和简单碰撞提供真实的体积，而不是做展示级雕刻或复刻表面纹样。

代码在运行时不会读取这三张图片，也不会把图片贴到平面上；图片只用于观察结构、比例和支撑关系。模型全部由 `numpy` 数值和 `trimesh` 基本几何生成。

## 运行方式

环境要求：

- Python 3.12
- `numpy`
- `trimesh`

在 `trial-01` 目录运行：

```bash
python build_models.py
```

脚本会自动创建 `outputs/`，并导出：

- `outputs/umbrella.glb`
- `outputs/vase.glb`
- `outputs/chair.glb`

每个 GLB 由一个或多个带面颜色的网格节点组成，不使用贴图，也没有外部依赖文件。

## 统一坐标与尺寸约定

每个模型在导出前统一做一次边界框归一化：

- Z 向上；
- 最低点固定在 `Z = 0`；
- XY 边界框中心固定在原点；
- 最长边归一化为 `2.0`；
- 所有顶点保持 Z-up 数值坐标，没有为了 glTF 默认的 Y-up 观看习惯额外旋转模型。若用只认 Y-up 的查看器打开，需要自行设置坐标轴或旋转。

三个模型归一化后的近似包围盒：

| 文件 | X 宽度 | Y 深度 | Z 高度 | 说明 |
|---|---:|---:|---:|---|
| `umbrella.glb` | 约 1.88 | 约 1.88 | 2.00 | 伞面直径略小于总高 |
| `vase.glb` | 约 1.30 | 约 1.30 | 2.00 | 旋转对称 |
| `chair.glb` | 约 1.41 | 约 0.81 | 2.00 | 正面宽、侧面薄 |

主要尺寸集中在 `build_models.py` 顶部的 `PARAMS` 中。比例调整优先修改这里：

- `PARAMS["umbrella"]`：伞面半径、伞面弧度控制点、伞骨数量、伞杆长度、顶饰与流苏位置；
- `PARAMS["vase"]`：外轮廓和内腔轮廓、分段数、口沿与底部的蓝色高度带；
- `PARAMS["chair"]`：座面、四腿、扶手、搭脑、靠背镂空格、下部横枨的所有主要尺寸。

颜色集中在 `COLORS` 中，只是便于区分材质，不属于图片纹样复刻。

## 从图片识别出的结构

### 1. `umbrella.png`：木柄油纸伞

识别到的可见结构：

- 一张很大的圆形/多边形纸伞面，中心明显高于外缘，边缘略微下垂；
- 伞面由多根径向伞骨支撑，伞骨末端在边缘形成小凸出；
- 中心有伞头和木质顶饰，下面是贯穿伞面的直伞杆；
- 伞杆下部有车木手柄/握把，底端挂着红色流苏（珠结加下垂的穗体）。

代理模型的处理：

- 伞面是有厚度的旋转薄壳，截面沿半径分成多个折面，保留伞面的拱起、边缘悬挑和伞下空间；
- 24 根径向伞骨位于伞面下方，从中心毂连接到接近外缘的位置，末端再加小段骨尖；
- 增加从伞杆滑套到伞骨的短撑杆和中心毂，明确“伞面 → 伞骨/撑杆 → 伞杆”的支撑关系；
- 中心孔由木质顶盖遮住，顶饰继续向上形成最高的尖端；
- 伞杆、车木握把、红色珠结和喇叭形流苏裙均为有体积的实体；
- 伞面和伞下空间之间是真正的悬空/开放区域，不是平面卡片。

不可见部分的假设：

- 伞面是理想旋转体，原图的花卉绘画、纸张纹理和局部折痕省略；
- 从背面看不到的伞骨按规则径向排列，数量简化为 24 根；
- 伞面纸层厚度、握把内部被遮住的伞杆、流苏穗体的具体束数根据体积合理性补全；
- 顶盖、伞骨与伞杆的连接采用简化实体相交，不模拟真实竹木榫接。

### 2. `vase.png`：青花瓷瓶

识别到的可见结构：

- 平底、外撇的圈足；
- 圆鼓的丰肩大腹，轮廓从下腹向外鼓出后缓慢收肩；
- 高领、束颈，口部再次外撇；
- 口沿内部可见暗部，说明这是一个有内腔的开口器皿；
- 无耳、无把手；
- 表面纹样是蓝白青花，但不属于本次代理模型的必要结构。

代理模型的处理：

- 用外轮廓和内腔轮廓共同旋转生成一个真正中空、顶部开口的瓶体；
- 平底落在 `Z = 0`，底部是一个完整支撑面；
- 口沿由外壁、内壁和顶部环形唇面连接，内部空腔向下延伸到接近器身下部；
- 旋转对称的几何可以自然从正面、侧面和背面观察，背面的轮廓与正面一致；
- 仅用面颜色区分瓷白主体、蓝色口沿和蓝色底足，不绘制花朵、枝叶或边饰。

不可见部分的假设：

- 图中不可见的后壁按旋转对称补全；
- 瓷壁厚度、内腔深度和内底厚度不可从单张正面图直接读出，按厚壁瓷器的比例假设；
- 假定底部平整、无穿孔，器物稳定立于平面；
- 纹样、釉面和青花细节完全省略。

### 3. `chair.png`：中式木扶手椅

识别到的可见结构：

- 四条方腿，前面两腿向上延伸支撑扶手，后腿继续向上成为靠背立柱；
- 高靠背，顶部有横向搭脑，两端略有外挑和抬高；
- 靠背中央有一块竖向的透雕靠背板，内部是镂空的格状图案，孔洞可透光；
- 两侧扶手从靠背向前伸出，由前腿支撑；
- 方形座面，座面下有束腰/牙板一类的横向构件；
- 腿部之间有下部横枨，形成开放框架；
- 座面、扶手和搭脑都有超出腿部的悬挑。

代理模型的处理：

- 座面用一块有厚度的实体板，四腿、座面牙板、扶手、靠背立柱和搭脑分别有真实截面；
- 靠背中央板不是实心板，而是由边框、两根内竖棂和三根横棂组成的真实贯通格栅，孔洞一直透到背面；
- 后腿从地面连续延伸到搭脑，形成背部支撑；前腿连续延伸到扶手；
- 四腿之间保留真实的开放空间，下部设前后横枨和左右侧枨，形成稳定的 H 形框架；
- 搭脑两端用抬高的小块体表现原图的外挑端部；
- 座面略高于横枨，座面下保留牙板和空腔，便于投影表现。

不可见部分的假设：

- 扶手、靠背和搭脑的真实截面与后侧弧度在图中被透视遮挡，这里用矩形截面的直线构件简化；
- 原图的软屉/编织座面在代理模型中简化为实体木板；
- 中央透雕的具体曲线纹样不复制，保留为规则格栅孔洞，保证遮挡关系和透光孔存在；
- 榫卯、内部连接件和后腿的细微收分省略。

## 几何实现要点

- 旋转体：使用自定义 `_lathe()`，支持实心端点、 hollow 开口和封闭薄壳三种轮廓，避免依赖布尔运算或额外几何库。
- 薄壳伞面：使用闭合截面绕 Z 轴旋转，形成有厚度的环形伞面；内孔用木质顶盖封闭。
- 中空瓶：外轮廓与内腔轮廓在同一旋转体中连接，口沿是真实环面，内腔是真实凹空间。
- 镂空椅背：用多个细长方体拼成框和棂条，因此格眼是实际孔洞，不是贴图或低透明度面片。
- 每件模型导出前都会重新计算并检查：
  - `min(Z) == 0`；
  - XY 边界框中心为原点；
  - 最大边界尺寸为 `2.0`。
- 所有网格使用面颜色（face colors）表达材质分区，不包含纹理、UV、骨骼或动画。

## 依赖与边界

- 仅依赖 `numpy` 和 `trimesh`；未使用 `shapely`、`manifold3d` 或其他布尔/建模包。
- 未读取或复用其他目录中的模型、图片、工程代码。
- 未联网、未安装依赖、未调用图像生成或其他模型。
- 导出格式为 GLB，文件中的几何坐标保持本说明的 Z-up 约定。
